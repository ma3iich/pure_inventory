## Modifications

Pure Inventory is a modified version of Ox Inventory 2.45.1. The first commit of this repository is the original code,
unchanged; every change made by ma3iich since is in the git history. Main changes: 3D character preview, clothing slots,
rename in the slot, new interface driven by `config.lua`, standalone mode, framework detection, server hardening
(full list in the README, "Changes from ox_inventory").
